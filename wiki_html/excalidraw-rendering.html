Diagram Tools

Excalidraw rendering

Local PNG/SVG rendering for Excalidraw diagrams through an MCP server, headless Chromium, and agent-friendly output paths.

How It WorksInstallPrivacyVault UsesRelated
01

How It Works

The server exposes tools for reading the Excalidraw element format and rendering element JSON to PNG or SVG.

agent prompt
-> Excalidraw element JSON
-> headless Chromium singleton
-> @excalidraw/excalidraw import
-> exportToSvg()
-> SVG or Playwright PNG screenshot
The renderer uses headless Chromium to convert Excalidraw elements into SVG or PNG files.
02

Installation Shapes

claude mcp add --scope user --transport stdio excalidraw -- npx -y excalidraw-render
npx -y excalidraw-render

For source installs, clone the repository, install dependencies, build it, and point the MCP config at the built dist/index.js.
