Object Detection

Identifying what objects are in an image and where they are — bounding boxes and class labels for multiple localized predictions. Detection extends image classification from one global label to variable-count spatial outputs.

01

Task Taxonomy

Four related vision tasks with increasing spatial complexity:

TaskOutputSpatial info
ClassificationSingle label (e.g., CAT)None — "no spatial extent"
Semantic SegmentationPer-pixel labels (GRASS, CAT, TREE, SKY)Pixels only — "no objects, just pixels"
Object DetectionBounding boxes + class labelsMultiple objects with locations
Instance SegmentationPer-pixel labels per instanceMultiple objects with pixel-precise boundaries

Given an image, object detection outputs: a set of bounding boxes (x, y, width, height), a class label for each box, and a confidence score for each prediction.

02

Two-Stage Detectors (RCNN Family)

Two-stage detectors first generate region proposals, then classify each proposal.

R-CNN

  1. Use Selective Search to generate ~2000 candidate regions
  2. Warp each region to a fixed size
  3. Pass each through a CNN to extract features
  4. Classify with SVM, refine bounding box with regression

Problem: very slow — 2000 forward passes per image. Paper: R-CNN

Fast R-CNN

Process the entire image with CNN once → shared feature map. Project region proposals onto the feature map (ROI pooling). Classify all regions from the shared features. Much faster than R-CNN.

Faster R-CNN

End-to-end pipeline using a Region Proposal Network (RPN):

  1. Image → CNN backbone → feature map
  2. Feature map → RPN → proposals (candidate bounding boxes)
  3. Feature map + proposals → ROI pooling → fixed-size features per proposal
  4. Features → Classification head → class labels + bounding-box regression

Both classification loss and bounding-box regression loss are trained jointly end-to-end. Paper: Faster R-CNN

03

Single-Stage Detectors

Single-stage detectors predict bounding boxes and classes directly in one pass — faster but historically less accurate than two-stage.

YOLOYou Only Look Once

Grid-based end-to-end detection

  • methodDivide image into S×S grid; each cell predicts B boxes + C class probs
  • speedOne forward pass — all predictions simultaneously
  • tradeoffLess accurate on small objects
  • versionsYOLOv2/v3 and many subsequent iterations
speed: very fast

SSDSingle Shot MultiBox

Multi-scale anchor boxes

  • methodFeature maps at multiple scales for anchor boxes
  • speedFast single-pass inference
  • tradeoffBetter at small objects than original YOLO
  • anchorsPre-defined aspect ratios and scales
speed: fast

RetinaNetFocal Loss

Two-stage accuracy at single-stage speed

  • methodFocal Loss addresses class imbalance from easy background examples
  • speedFast single-pass inference
  • tradeoffAchieves two-stage accuracy at single-stage speed
  • key ideaDown-weights easy negatives in training loss
speed: fast
04

DETR: Detection Transformer

Facebook DETR was the first object detector to frame detection as a direct set prediction problem using a Transformer:

  • No anchor boxes, no non-maximum suppression (NMS)
  • CNN backbone extracts features → Transformer encoder-decoder predicts object set
  • Bipartite matching loss during training aligns predictions to ground truth
  • Simpler pipeline but slower training convergence than RCNN
from transformers import pipeline
detector = pipeline("object-detection", model="facebook/detr-resnet-50")
result = detector(image)

Paper: End-to-End Object Detection with Transformers (DETR)

05

Anchor Boxes

Most non-DETR detectors use anchor boxes — predefined bounding box shapes at each spatial location. The model predicts offsets and class scores relative to anchors. Different anchors cover different aspect ratios and scales. DETR eliminates the need for anchors entirely, simplifying the detection pipeline at the cost of longer training.

06

Evaluation: mAP

Mean Average Precision (mAP) is the standard evaluation metric:

  • Compute precision-recall curve for each class
  • Average precision (AP) = area under the curve
  • mAP = mean AP across all classes
