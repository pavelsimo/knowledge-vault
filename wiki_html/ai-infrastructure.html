02

Why CPUs Matter

Many agent-loop operations are CPU-native: shell commands, file management, API calls, browser automation, parsing, scheduling, network I/O, and verification scripts. Even when token generation runs on an accelerator, the surrounding harness work often runs on CPU.

04

Practical Bottlenecks

  • Worktrees duplicate dependencies.
  • Compilers and test runners compete for RAM.
  • Browser automation consumes CPU and memory.
  • OCR, vector stores, and document conversion add background load.
  • Long-running sessions need stable process supervision.

For local agent swarms, machine resources can be the limiting factor before model cost.
