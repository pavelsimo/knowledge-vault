PyTorch Building Blocks

ConceptMeaning
nn.LinearApplies input @ W.T + bias
SoftmaxTurns logits into probabilities
OptimizerUpdates parameters after gradients are computed
zero_grad()Clears accumulated gradients
view()Reshapes tensors without changing values
torch.tril()Builds lower-triangular causal masks

The key mental model: during training, tensors carry both values and the computation graph needed by loss.backward().

02

Character Tokenization

chars = sorted(set(text))
string_to_int = {ch: i for i, ch in enumerate(chars)}
int_to_string = {i: ch for i, ch in enumerate(chars)}
encode = lambda s: [string_to_int[c] for c in s]
decode = lambda ids: "".join([int_to_string[i] for i in ids])

Character tokenization is intentionally simple. It exposes the mechanics that production BPE or SentencePiece tokenizers hide.

03

Bigram Model

A bigram model predicts the next token using only the current token. Its learned parameter is an embedding table where each row scores possible next tokens.

class BigramLanguageModel(nn.Module):
    def __init__(self, vocab_size):
        super().__init__()
        self.token_embedding_table = nn.Embedding(vocab_size, vocab_size)

The output shape is (B, T, vocab_size): batch, sequence length, and one score per vocabulary token.

04

Training Loop

xb, yb = get_batch("train")
logits, loss = model(xb, yb)
optimizer.zero_grad(set_to_none=True)
loss.backward()
optimizer.step()

Targets are the input shifted one token right. Cross-entropy penalizes the model when it assigns low probability to the actual next token.

B, T, C = logits.shape
logits = logits.view(B * T, C)
targets = targets.view(B * T)
loss = F.cross_entropy(logits, targets)
05

Generation

logits, _ = model(index)
logits = logits[:, -1, :]
probs = F.softmax(logits, dim=-1)
next_token = torch.multinomial(probs, num_samples=1)
index = torch.cat((index, next_token), dim=1)

This is autoregressive inference in miniature. Modern decoder-only transformers use the same outer loop with attention blocks, positional encodings, and KV cache.
