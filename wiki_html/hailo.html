Hailo AI Accelerator

The Hailo-8 is a dedicated AI inference accelerator chip for edge deployment, offering high-throughput neural network inference at low power. Setup spans two machines: a client (ARM/Raspberry Pi running inference via HailoRT) and a server (x86_64 running the Dataflow Compiler to compile ONNX models into .hef files).

ComponentRoleHost
HailoRTRuntime library + PCIe driver for inferenceARM64 (e.g. Raspberry Pi)

Hailo Model ZooPre-built model configs (YAML + .alls)x86_64 Ubuntu
.hef fileCompiled hardware-executable modelDeployed to client

The .hef (Hailo Executable Format) is the compiled artifact produced by the Dataflow Compiler and loaded by HailoRT at inference time. The split architecture means the heavy compilation work (which requires a calibration dataset and x86 tools) happens once on a development machine; the resulting .hef is then deployed to the edge device.

03

Setup Walkthrough

HailoRT — Client Installation (ARM64 / Raspberry Pi)

Prerequisites: Ubuntu ARM64 with Hailo-8 over PCIe, Python 3.12. Download packages from the Hailo Developer Zone.

export HAILO_VERSION=4.23.0
export HAILO_ARCH=$(dpkg --print-architecture)

sudo dpkg --install \
  hailort_${HAILO_VERSION}_${HAILO_ARCH}.deb \
  hailort-pcie-driver_${HAILO_VERSION}_all.deb

pip install hailort-${HAILO_VERSION}-cp312-cp312-linux_aarch64.whl
pip install -r requirements.txt
!
After installation, fix the PCIe descriptor page size — the default (16384) exceeds the hardware maximum (4096) and causes runtime errors. See the "Fix Common Issues" tab.

Dataflow Compiler — Compile ONNX to .hef (x86_64)

Prerequisites: Ubuntu x86_64, Python 3.10, at least 1024 calibration images for post-training quantization.

sudo apt-get install -y cmake python3.10 python3.12-venv python3.10-dev \
  python3-tk graphviz libgraphviz-dev pkg-config

python3.10 -m venv .venv
source .venv/bin/activate

pip install hailo_dataflow_compiler-3.33.1-py3-none-linux_x86_64.whl
pip install hailo_model_zoo-2.18.0-py3-none-any.whl

Once the environment is ready, compile your ONNX model:

hailomz compile \
  --ckpt best.onnx \
  --hw-arch hailo8 \
  --classes 3 \
  --calib-path /path/to/calibration/images/ \
  --yaml .venv/lib/python3.10/site-packages/hailo_model_zoo/cfg/networks/yolo26n.yaml

Fix: PCIe Descriptor Page Size

The default descriptor page size (16384) exceeds the hardware maximum (4096), causing runtime errors. Fix and persist:

sudo modprobe -r hailo_pci
sudo modprobe hailo_pci force_desc_page_size=4096
echo "options hailo_pci force_desc_page_size=4096" | sudo tee /etc/modprobe.d/hailo_pci.conf

Fix: Calibration Images (EXIF / Colorspace Issues)

Some images fail calibration due to EXIF orientation metadata or non-RGB colorspaces. Strip and normalize:

mkdir -p /tmp/hailo_calib_clean
find ./train/images/ -type f | while read -r f; do
  base="$(basename "${f%.*}")"
  convert "$f" -auto-orient -strip -alpha off -colorspace sRGB \
    "/tmp/hailo_calib_clean/${base}.jpg"
done

Then point --calib-path to /tmp/hailo_calib_clean/ instead of the raw training images.

04

Key Concepts

ConceptExplanation
Post-training quantization (PTQ)The Hailo DFC quantizes the model during compilation using calibration images to minimize accuracy loss. At least 1024 images required — more is better for representing distribution diversity.
.alls configControls compilation parameters (e.g. calib-size). Found under hailo_model_zoo/cfg/alls/. Edit to tune quantization behavior per model.
hailomz CLICLI entry point for the Hailo Model Zoo; wraps DFC with model-specific YAML configs. Handles the full compile-optimize-quantize pipeline in one command.
HailoRT Python bindingsAllow inference calls directly from Python on the client device. Loads the .hef, manages input/output buffers, and returns predictions.
.hef formatHailo Executable Format — the compiled, quantized, chip-optimized model. Analogous to a compiled binary; not human-readable. Must be recompiled for different Hailo chip variants.
