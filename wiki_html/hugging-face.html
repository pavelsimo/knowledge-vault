Model Hub

How Models Are Organized

Models are hosted as repositories containing weights, configs, and tokenizer files. Models can have multiple checkpoints — snapshots of saved weights at different training stages. Loading a model technically means loading a checkpoint (pre-trained weights + configuration).

FormatNotes
pytorch_model.binLegacy format; serialized PyTorch checkpoint via torch.save()
.safetensorsModern format; safer (no arbitrary Python execution), faster (memory-mapped), portable across frameworks
!
Memory note: A loaded model needs ~10–30% more memory than the raw checkpoint file size. Example: model.safetensors = 1.62 GB → ~2.1 GB RAM needed at runtime.

Depending on your hardware, you may not be able to run the largest checkpoints.

Task Categories

Hugging Face organizes models by task type. Key categories:

  • Chat Completion — conversational LLMs and instruction-following models
  • Feature Extraction — embedding models for semantic search and retrieval
  • Automatic Speech Recognition — audio-to-text transcription (e.g., Whisper)
  • Text to Video — generative video from text prompts
  • Object Detection — locate and classify objects in images
  • Image Segmentation — pixel-level mask generation
  • Depth Estimation — monocular depth from single images
  • Image-Text Matching — cross-modal similarity and retrieval
  • Machine Translation — multilingual text translation
  • Zero-shot Audio Classification — classify audio without task-specific training

Evaluation and Rankings

Hugging Face hosts the community's primary model evaluation infrastructure:

  • Open LLM Leaderboard — tracks, ranks, and evaluates open LLMs and chatbots across standardized benchmarks
  • LM Arena — crowdsourced human preference rankings across LLMs on versatility, linguistic precision, and cultural context

These leaderboards are the primary mechanism by which the open-source community competes with proprietary models and tracks progress across capability dimensions.

Tools & Chat Interface

Beyond model hosting, Hugging Face provides:

  • Chat interface — chat with open-source models at huggingface.co/chat
  • Spaces — hosted ML demos and interactive apps (Gradio, Streamlit)
  • Inference API — hosted inference for thousands of models without local setup
  • Datasets — repository for training and evaluation datasets
  • Transformers library — unified Python API for loading and running models
★
The Transformers library is the primary way to load any Hugging Face model into Python code for local inference or fine-tuning.

Pretrained vs Fine-tuned Models

TypeDescription
PretrainedTrained from scratch on large corpora by big companies with significant compute
Fine-tunedPretrained models further trained on a specific task or domain
DistilledCompressed versions of larger "teacher" models, trained on the teacher's outputs rather than raw human data; designed to be faster and cheaper while retaining accuracy
