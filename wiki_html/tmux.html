Tmux for sessions

A terminal multiplexer for persistent sessions, windows, panes, long-running shell work, and local agent orchestration.

Session Commands

CommandDescription
tmuxStart a new session
tmux new -s <name>Start a named session
tmux new-session -A -s <name>Attach or create named session
tmux lsList sessions
tmux a -t <name>Attach to a specific session
tmux kill-session -t <name>Kill one session

03

Agent Workflows

Tmux gives every long-running process a stable terminal target. This is useful for isolated coding agents, mid-task redirection, logging, and reattachment.

tmux new-session -d -s codex-feature -c /path/to/worktree "codex"
tmux send-keys -t codex-feature "Focus on the API layer first." Enter
tmux attach -t codex-feature
04

Recommended Config

set -g mouse on
set -g mode-keys vi

Mouse support helps with pane selection and scrolling. Vi mode makes copy-mode navigation line up with common terminal muscle memory.
