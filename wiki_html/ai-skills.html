AI skills

Reusable folders of instructions, examples, evals, and memory that let an assistant perform recurring tasks without reloading every detail into the conversation.

01

What a Skill Contains

A skill is a directory that the AI can trigger for a task. The source's example is an editing skill for long-form posts, but the structure generalizes.

LayerPurpose
SKILL.mdConcise workflow and rules loaded when the skill triggers
DescriptionRouting signal that tells the assistant when to load the skill
ExamplesReference outputs loaded only when relevant
evals.mdPass/fail checks that grade the output
memory.mdShort lessons from previous uses
Skill editorA meta-skill for keeping other skills concise and readable
The key rule is progressive disclosure: keep the main instructions short, and put bulky examples or personal context in separate files.
02

Build Workflow

  1. Give the AI best examples and personal context, then ask it to draft the skill.
  2. Audit the description so the skill triggers reliably.
  3. Test the skill manually on real input.
  4. Add pass/fail evals and make the skill loop until checks pass.
  5. Add concise memory for lessons that improve the skill over time.

This is Agent Harness thinking at skill scale. The skill is not just prose instructions; it is a repeatable loop with state, examples, evaluation, and revision.

03

Evals Beat Vibes

The most useful evals are concrete pass/fail checks, not vague scores. The tutorial is skeptical of numeric grading because LLMs often cannot consistently distinguish adjacent scores.

  • Does the intro contain a clear hook?
  • Does the tutorial include the required link or call to action?
  • Are banned phrases absent?
  • Is the output practical enough for the target reader?
  • Does the final section ask the reader to take a concrete next step?

For higher-quality grading, use a separate agent or clean context window to run evals. That reduces bias from the editing agent's own previous work.

04

Memory Without Bloat

Skill memory should capture lessons that are hard to encode as pass/fail rules. It should not duplicate the eval file.

Use memory forUse evals for
Taste and tone changesRequired sections
User preference shiftsBanned phrases
Lessons from previous sessionsOutput structure checks
Fuzzy quality feedbackConcrete pass/fail constraints
05

Human Taste Remains

Even a strong skill may get an output most of the way there. Human judgment still matters for the last pass, especially where taste, context, or reputational risk is involved.

This connects to Recursive Self-Improvement: reusable skills, eval loops, and memory can make AI-assisted work compound, but the bottleneck shifts toward judgment, review, and verification.
