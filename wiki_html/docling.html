Docling for extraction

A local document-conversion stack for OCR, table extraction, provenance metadata, content layers, and agent-friendly Markdown or JSON exports.

Pipeline Shape

Docling turns messy documents into structured documents, Markdown, JSON, and chunks. The practical architecture is extraction first, retrieval later.

PDF or document source -> Docling -> JSON/Markdown -> HybridChunker -> embeddings -> vector DB -> LLM

02

Mixed PDFs and OCR

Docling can handle PDFs that mix native digital text and scanned pages. Digital pages use text extraction, scanned regions use OCR, and mixed pages combine both while filtering spatial duplicates.

options.do_ocr = True
options.ocr_options = RapidOcrOptions()
options.images_scale = 2.0
options.do_table_structure = True
markdown = result.document.export_to_markdown(traverse_pictures=True)
CPU-only default: RapidOCR is the recommended local OCR choice when speed, privacy, and cost matter. Use VLMs selectively only for pages whose layout fails conventional OCR/table extraction.
03

Chunking and Provenance

HybridChunker creates token-bounded chunks while preserving links back to original document elements. Each chunk has chunk.meta.doc_items; each item may carry page, bounding-box, and character-span provenance.

for item in chunk.meta.doc_items:
    for prov in getattr(item, "prov", []):
        print(prov.page_no, prov.bbox, prov.charspan)
FieldMeaning
page_noSource page number
bboxAbsolute coordinates, not normalized
charspanCharacter range in the source item
repeat_table_headerRepeats headers when large tables split across chunks
04

Content Layers and DOCX Images

Docling excludes page furniture such as headers and footers from exports by default. Include ContentLayer.FURNITURE when repeated document metadata is meaningful.

md = doc.export_to_markdown(
    included_content_layers={ContentLayer.BODY, ContentLayer.FURNITURE}
)

DOCX images may export as [image] placeholders. For VLM image understanding, convert DOCX to PDF first, then configure the PDF format with pipeline_cls=VlmPipeline.
