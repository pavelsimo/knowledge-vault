Recurrent neural networks

RNNs are neural networks designed for sequential data where the order of elements matters. Unlike feedforward networks, RNNs maintain an internal hidden state that acts as memory, allowing them to carry information across time steps.

01

Vanilla RNN (Elman RNN)

The simplest RNN, named after Prof. Jeffrey Elman. The state consists of a single hidden vector h:

hₜ = tanh(Whh · hₜ₋₁ + Wxh · xₜ)    ← hidden state update
yₜ = Why · hₜ                          ← output (when needed)

Three weight matrices: Whh (hidden-to-hidden), Wxh (input-to-hidden), Why (hidden-to-output). The tanh activation squashes values to [-1, 1].

The hidden state is the internal memory of the RNN — it summarizes everything the model has seen up to time t. The same weight matrix W is used at every time step — this is what makes it "recurrent."

Truncated Backpropagation Through Time (TBPTT)

Full BPTT through very long sequences is computationally intractable. TBPTT processes in chunks:

  • Carry hidden states forward through time forever (full sequence)
  • Only backpropagate for a smaller fixed number of steps
  • Breaks the sequence into windows; gradients don't flow further back than the window

CNN + RNN for image captioning

Image → CNN encoder → initial hidden state h₀
h₀ → RNN: [START] → "straw" → "hat" → END → yₜ

The CNN encodes visual features, initializes the RNN hidden state, and the RNN generates words autoregressively.

RNNs can be configured for different input-output patterns:

ModePatternExample
One-to-one1 input → 1 outputStandard classification
One-to-many1 input → sequence outputImage captioning: image → sentence
Many-to-oneSequence input → 1 outputSentiment: sentence → positive/negative
Many-to-many (synced)Seq → seq (same length)Video: each frame → action label

Applications

  • Language modeling (predict next word)
  • Machine translation (seq-to-seq)
  • Sentiment analysis
  • Time series prediction
  • Music generation
03

Vanishing gradient problem

When backpropagating through many time steps, the gradient is multiplied by the same weight matrix repeatedly:

  • If weights are slightly < 1: gradients shrink exponentially → vanish
  • If weights are slightly > 1: gradients grow exponentially → explode

Result: vanilla RNNs effectively only remember ~10–20 steps back.

!
Gradient explosion is handled by gradient clipping. Gradient vanishing requires architectural solutions — that's where LSTM comes in.
04

Vanilla RNN vs LSTM vs Modern RNNs

Vanilla RNN

hₜ = tanh(Whh · hₜ₋₁ + Wxh · xₜ)
  • Single hidden state stream
  • Simple and fast
  • Cannot handle long-range dependencies (vanishing gradients)
  • Effective memory: ~10–20 steps

Tradeoffs:

  • Unlimited context length in theory, but fails in practice
  • Cannot be parallelized — must process sequentially
  • Linear compute per step

Finding Structure in Time (Elman, 1990)

LSTM — Long Short-Term Memory

LSTMs address vanishing gradients with gates and a separate cell state:

  • hₜ — hidden state (short-term memory)
  • cₜ — cell state (long-term memory, modified by gates)

The four gates:

GatePurpose
Forget gate fₜWhat to erase from cell state
Input gate iₜWhat new information to write
Cell gate g̃ₜCandidate values to add
Output gate oₜWhat part of cell state to expose
 
cₜ = f ⊙ cₜ₋₁ + i ⊙ g    ← cell state update (forget old, write new)
hₜ = o ⊙ tanh(cₜ)         ← hidden state (what to expose)

The cell state behaves like a highway — gradients can flow back without being repeatedly multiplied, similar to ResNet skip connections.

If forget gate f = 1 and input gate i = 0, the cell state cₜ = cₜ₋₁ — information is preserved indefinitely. LSTM doesn't guarantee no vanishing/exploding gradient, but provides an easier path to learn long-distance dependencies.

Long Short-Term Memory (Hochreiter & Schmidhuber, 1997)

Modern RNN architectures (2023–present)

Recent architectures revisit RNNs with significant improvements:

  • Mamba (2023) — selective state space model with input-dependent state transitions
  • RWKV — recurrent model with transformer-level performance
  • xLSTM — extended LSTM with improved scaling properties

Advantages over transformers:

  • Unlimited context length — major advantage (transformers are quadratic in sequence length)
  • Linear compute scaling with sequence length vs transformers' quadratic scaling
  • Actively competing with transformers for long-sequence tasks

These architectures address the core limitation of old RNNs (sequential processing) while maintaining the memory advantage (linear-time inference).

05

Encoder-decoder bottleneck and attention

Classical sequence-to-sequence RNNs compress the entire input into one final hidden state, then ask the decoder to generate everything from that single vector:

Input sequence → RNN encoder → final state c → RNN decoder → output sequence

This works on short sequences, but creates an information bottleneck on long inputs: the model must remember everything important in one fixed-size state.

Attention as the fix

The attention mechanism (now used in transformers) was originally developed to overcome this RNN limitation in machine translation. Instead of one context vector:

  • Encoder produces h₁, h₂, h₃, h₄ for all input tokens
  • At each decoder step, the context vector cₜ is a different weighted combination of all encoder states
  • The model "looks at" different parts of the input sequence at each output step

See attention-transformers — the attention mechanism born from RNN limitations, now dominant.

Classical seq2seq uses one fixed context vector for the whole output.
06

Historical context and related topics

LSTMs saw enormous success in NLP before the transformer revolution (2017–2018). The key papers in the RNN → attention → transformer lineage:

  • Sequence to Sequence Learning with Neural Networks — standard seq2seq paper
  • Bahdanau et al. 2015 — "Neural machine translation by jointly learning to align and translate" — introduced attention to RNNs
  • Vaswani et al. 2017 — "Attention Is All You Need" — replaced RNNs with pure self-attention
